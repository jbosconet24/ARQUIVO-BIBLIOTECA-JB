⚠ Precauções

  • Dados ficam no localStorage do navegador. Não limpe o cache sem exportar o JSON antes.
  • Não use modo anônimo — o localStorage não persiste.
  • Exporte o JSON periodicamente como backup soberano.
  • Excluir um item é permanente — sem desfazer.
  • Ao usar em outro PC ou navegador, importe o JSON.

O que é o app

Biblioteca local de metaprompts, prompts, frames e documentos do ecossistema ARQ.JB. Roda offline no navegador. Dados salvos no localStorage. Sync com a Arquivista via bocal JSON.

Cadastrar um item

1
Arraste um .txt para a zona de drop ou cole o conteúdo no campo de texto.
2
O app tenta preencher nome, versão e categoria automaticamente. Revise.
3
Se houver item similar, o app avisa antes de salvar.
4
Clique Salvar. Item entra numerado por ordem cronológica.

Versionar

1
Abra a ficha do item → botão "Nova versão".
2
Edite o conteúdo, ajuste a versão. Salve.
3
A linhagem aparece como pílulas na ficha de qualquer item da cadeia.

Sync com a Arquivista

1
Na Arquivista: exportar catálogo → copia o JSON.
2
No app: aba Bocal → cola → Sincronizar.
3
Para fechar o ciclo: Gerar saída p/ Arquivista → copia → na Arquivista: importar do app.

Backup

1
Exportar → Exportar JSON → salvar o arquivo em local seguro (Drive, OneDrive, etc).
2
Para restaurar: Exportar → Importar JSON.
3
O app avisa quando faz mais de 7 dias sem backup.
